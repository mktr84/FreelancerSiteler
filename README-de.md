## 📖 Über das Projekt

Remote & Freelance Plattform-Übersicht ist ein umfassendes Verzeichnis für Fachleute, die nach Remote-Arbeit und Freelance-Möglichkeiten suchen. Es bietet ein Glassmorphism-UI-Design, mehrsprachige Unterstützung (🇹🇷 Türkisch, 🇬🇧 Englisch, 🇩🇪 Deutsch) und eine moderne, responsive Benutzeroberfläche.

## 🛠️ Technologien

- **Glassmorphism UI** — Modernes Milchglas-Schnittstellendesign
- **Mehrsprachig** — Türkisch, Englisch, Deutsch
- **Responsives Design** — Vollständig kompatibel auf allen Geräten
- **Keine Abhängigkeiten** — Reines HTML/CSS/JS, keine Frameworks erforderlich

## ⚡ Erste Schritte

```bash
git clone https://github.com/mktr84/FreelancerSiteler.git
cd FreelancerSiteler
```

Öffne `index.html` in deinem Browser — kein Server erforderlich.
